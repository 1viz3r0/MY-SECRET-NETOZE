NET0ZE v2.0.0

NETWORK TRAFFIC ANALYSIS & SECURITY MONITORING

QUICK START
------------

1. Open:                            01 - INSTALL NET0ZE

2. Double-click:                    INSTALL NET0ZE v2.0.0.exe

3. Complete the installer.

4. Launch NET0ZE from the Start Menu.

5. Open the Capture section.

6. Select your Wi-Fi/network adapter.

7. Start Capture.

8. Browse the Internet normally for a few minutes.

9. Return to NET0ZE and inspect:

   - Global Intel
   - Live Flows
   - DNS
   - Detections
   - Attack Graph
   - Hybrid Intel
   - Devices
   - Ports
   - Threat Intel
   - Audit Logs

IMPORTANT
---------

NET0ZE uses real network telemetry.

Empty sections can be normal when there is no corresponding real data.

Do not expect fake/demo traffic.

REQUIREMENT (ONLY FOR LIVE PACKET CAPTURE)
------------------------------------------

Npcap is NOT bundled with NET0ZE. Live capture needs Npcap installed:
https://npcap.com/

NET0ZE detects Npcap and shows its status. All other features work
without it. See README.txt inside "02 - PORTABLE NET0ZE"/"NET0ZE" for
details.

RECOMMENDED INSTALLER
---------------------

Use:

01 - INSTALL NET0ZE

The NSIS installer is the normal user installation. It creates the
NET0ZE Start Menu shortcut and handles WebView2 automatically.

PORTABLE VERSION
-----------------

Use:

02 - PORTABLE NET0ZE

if you do not want a normal installation (runs without installing).
